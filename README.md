# ConcreteNeed SEO Test

Focused GitHub Pages experiment for concrete-calculator search intent.

## Deploy
1. Create a public GitHub repository named `concrete-calculator`.
2. Upload all files in this folder to the repository root.
3. Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
4. Expected URL: https://kavindanipun.github.io/concrete-calculator/
5. Add the exact URL-prefix property to Google Search Console.
6. Keep the Google HTML verification file in the repository root after verification.
7. Submit `sitemap.xml` and request indexing for the homepage once.

If you choose a different repository name, update the canonical URL in index.html and URLs in robots.txt + sitemap.xml before deployment.
